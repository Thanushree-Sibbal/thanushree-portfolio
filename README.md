# S Thanushree — Portfolio

A responsive, static portfolio website for S Thanushree. Its visual direction uses a near-black canvas with electric lime, violet, and hot pink accents, oversized display typography, a layered portrait hero, floating code and MUN labels, scroll reveals, project walkthrough videos, achievements, leadership, skills, education, and recruiter contact links.

## Run locally

The site has no build step or package dependencies.

1. Unzip the complete folder if downloaded as an archive.
2. Open `index.html` in a modern browser.

For best media playback, serve the folder from a local web server (for example, in this directory run `python -m http.server 8000`, then open `http://localhost:8000`).

## Included files

- `assets/thanushree-profile.jpeg` — supplied profile photo
- `assets/S-Thanushree-Resume.pdf` — supplied Stibo résumé, linked from the site
- `assets/smartspender-demo.webm` — SmartSpender walkthrough
- `assets/gnn-demo.webm` — social network GNN walkthrough
- `assets/parampara-demo.mp4` — supplied WhatsApp video, used as the Parampara walkthrough

All text is in `index.html`; layout and visual styles are in `styles.css`; lightweight scroll/menu interactions are in `script.js`.
